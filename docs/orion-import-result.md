## Repeat Import

Повторный запуск без `--force` вернул:

```text
ALREADY_IMPORTED
```

Повторный запуск с `--force` разрешён и не создаёт дубли Product/SupplierOffer. Для этого файла Product/SupplierOffer остаются равны 0, так как валидных строк нет.

## Вывод

Mapping технически определён для доступных колонок, но полноценный импорт каталога из ORION невозможен без достоверного источника бренда. Без отдельной таблицы сопоставления `article -> brand` или нового прайса с колонкой бренда строки должны оставаться `invalid/review`, а не превращаться в товары с выдуманным брендом.
