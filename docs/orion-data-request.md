# Запрос данных у поставщика ОРИОН

Чтобы превратить прайс в качественный каталог автозапчастей, в следующей версии файла просим добавить или передать отдельным файлом следующие поля.

## Обязательные поля

| Поле | Зачем нужно |
| --- | --- |
| Производитель / бренд | Без бренда нельзя отличить товары с одинаковым артикулом у разных производителей. |
| Артикул производителя | Нужен для точного поиска, дублей и сопоставления с существующим каталогом. |
| Внутренний артикул ОРИОН | Нужен для связи с вашим прайсом и повторных обновлений. |
| Название товара | Нужно для карточки товара и ручной проверки сопоставления. |
| Категория | Нужна для навигации и фильтров каталога. |
| Остаток | Нужен для доступности товара. |
| Склад | Нужен для срока получения и корректного обновления остатков. |
| Закупочная цена | Нужна для расчёта цены продажи. |
| РРЦ или цена продажи | Нужна, если поставщик уже передаёт рекомендованную цену. |
| Срок поставки | Нужен для показа клиенту даты получения. |
| Дата обновления строки | Нужна, чтобы понимать актуальность цены и остатка. |
| Валюта | Нужна для корректного расчёта цены. |
| Единица измерения | Нужна для продажи по штукам, комплектам, литрам и т.д. |
| Минимальная партия | Нужна, если товар нельзя заказать по 1 штуке. |

## Желательные поля

| Поле | Зачем нужно |
| --- | --- |
| OEM | Помогает сопоставлять аналоги и оригинальные номера. |
| Применяемость | Позволяет проверять совместимость с автомобилем или техникой. |
| EAN / штрихкод | Помогает точнее идентифицировать товар. |
| Фото или ссылка на фото | Улучшает карточку товара и снижает ошибки подбора. |
| Вес и габариты | Нужны для расчёта доставки. |

## Почему текущего файла недостаточно

В текущем файле есть название, остаток, единица измерения, цена и артикул. Но нет бренда, производителя, категории, склада, срока поставки, OEM и применяемости.

Из-за этого нельзя безопасно создавать публичные товары автоматически. Один и тот же артикул может относиться к разным производителям, а слова в названии могут быть маркой техники, моделью, типом узла или частью описания. Поэтому такие строки сначала сохраняются в staging-слой и требуют ручного сопоставления.
