G-Garage mobile UX prototype

Основные маршруты

  • Карта всех экранов
  • Главная
  • Подбор по автомобилю
  • VIN-подбор
  • Каталог
  • Карточка товара
  • Корзина
  • Оформление
  • Личный кабинет
  • Менеджер

Реализованные сценарии

  • Главная -> поиск / VIN / подбор по авто / каталог / корзина.
  • Подбор по автомобилю: марка -> модель -> год -> двигатель -> сохранение -> совместимый каталог.
  • VIN-заявка: форма -> загрузка СТС -> предпросмотр -> отправка -> статус -> подборка -> сравнение -> корзина.
  • Каталог: категории, фильтры, сортировка, пустые и ошибочные состояния.
  • Товар: совместимость, аналоги, добавление в корзину и избранное.
  • Корзина: количество, промокод, изменения цены/срока, переход к оформлению.
  • Оформление без регистрации: контакты, доставка, ПВЗ, время, оплата, успех/ошибка.
  • Личный кабинет: заказы, автомобили, VIN-заявки, избранное, адреса, профиль.
  • Менеджер: VIN-очередь, карточка заявки, подбор товаров, заказы, статусы.

Ограничения

  • Backend, база данных, оплата, карты и внешние интеграции не подключены.
  • Данные моковые и живут только в памяти JavaScript во время сессии.
  • Менеджерский интерфейс является UX-прототипом, не полноценной админкой.
