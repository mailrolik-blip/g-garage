Responsive stage

  • Same routes now adapt for mobile, tablet, desktop and wide desktop.
  • Desktop customer flows include header, navigation, catalog filters, product purchase rail, checkout summary and account sidebar.
  • Manager routes use a desktop-first workspace with sidebar, topbar, VIN queue and order workspace.
  • Review mode includes Mobile, Tablet, Desktop and Side-by-side comparison controls.

Сценарии для ревью

  1. Главная -> поиск по артикулу -> товар -> корзина -> оформление -> заказ.
  2. Главная -> выбор автомобиля -> каталог совместимых товаров -> товар.
  3. Главная -> VIN-запрос -> статус -> подборка менеджера -> товар -> заказ.
  4. Каталог -> фильтры -> сортировка -> пустая выдача -> VIN-запрос.
  5. Товар не подходит -> аналог -> подходящий товар -> корзина.
  6. Цена или наличие изменились в корзине -> подтверждение -> оформление.
  7. Повторный клиент -> личный кабинет -> история -> повторить заказ.
  8. Менеджер -> VIN-очередь -> заявка -> подборка -> отправка клиенту.

Ограничения

  • Backend, база данных, оплата и интеграции не создавались.
  • Решения review-режима хранятся только в браузерном localStorage.
  • Рекомендации не удаляют экраны автоматически; финальное решение принимает владелец проекта.
